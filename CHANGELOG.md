## [1.0.0] — 2026-11-12

### Added

- Zero-dependency CLI: `install`, `add`, `validate`, `scaffold`, `list`, `doctor`.
- Bundled `add-skill` helper with checklists, security notes, and troubleshooting.
- Manual-only and auto-advertised install modes for opencode 1.x and 2.x.
- Whole-folder installs, Git sources, project scope, dry runs, and forced replacement.
- Skill validator for frontmatter, companion links, symlinks, size, and file count.
- Starter skill scaffolding with a self-contained check script.
- Interactive site with a 3D hero, skill builder, pattern library, quiz, learning path, and ROI
  sketch.
- Documentation for getting started, visibility, authoring, security, CLI, troubleshooting, and
  publishing.
- Tests using Node’s built-in test runner.
